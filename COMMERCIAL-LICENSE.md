# Commercial licensing

AURA is free, open-source software under the **GNU AGPL v3** (see [`LICENSE`](LICENSE) and
[`LICENSE-EXCEPTION.md`](LICENSE-EXCEPTION.md)). For most people that's all you need.

## You do not need a commercial licence to

- use AURA on your own phones, personally or at work
- study, modify, and fork the code
- ship your own build or fork, **as long as you publish its full source under the AGPL**
- run a service built on AURA, **as long as you publish its full source under the AGPL**
- charge money for any of the above. The AGPL allows selling; it only forbids hiding the source.

## You do need a commercial licence to

- ship AURA, or a product built on AURA's code, **without** publishing your source code
- combine AURA's code with proprietary code that you don't want to release under the AGPL
- offer a hosted or embedded version of AURA while keeping your changes private

A commercial licence gives you the same code under terms that let you keep your changes closed.
Licences are granted case by case by the copyright holder.

## How to ask

Contact the maintainer through their GitHub profile ([@Dinesh210805](https://github.com/Dinesh210805))
and say what you're building and how you plan to distribute it.

## Why this works

Every contributor signs the [Contributor License Agreement](CLA.md). The CLA lets the project
offer this commercial option for the whole codebase, not just the parts the maintainer wrote.
Contributors keep the copyright in their own work.
