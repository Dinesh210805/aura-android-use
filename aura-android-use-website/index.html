object SensitivePolicy {

    /** Why an action was refused — surfaced to the agent and the audit log. */
    enum class Category(val id: String) {
        FINANCIAL_APP("banking_or_payment_app"),
        AUTH_APP("authenticator_or_password_app"),
        BANKING_PATTERN("banking_keyword_app"),
        SENSITIVE_TEXT("sensitive_text_entry"),
        OTP_EXFILTRATION("otp_leaving_device"),
    }

    sealed interface Decision {
        data object Allow : Decision
        data class Block(val category: Category, val message: String) : Decision
    }

    /** Financial / payment apps — hard blocked on launch + deep link. */
    private val BLOCKED_FINANCIAL_PACKAGES = setOf(
        "com.google.android.apps.walletnfcrel", // Google Pay / Wallet
        "com.paypal.android.p2pmobile",         // PayPal
        "in.org.npci.upiapp",                   // BHIM

Connect your AI in four steps.

The same steps the AURA app shows on its MCP screen. Several AI apps can use the phone at once. Screen and taps travel directly, encrypted end to end; phone and computer need the same Wi-Fi, for now.

  1. Step 1 · one time

    Install the connector (Node.js 18 or newer)

    npm install -g aura-mcp-connect

  2. Step 2 · one time

    Pair this phone with the code AURA shows

    aura-mcp pair <PIN>

    The code works once, for 5 minutes.

  3. Step 3 · one time

    Add AURA to your AI app’s MCP config

    {
  "mcpServers": {
    "aura": { "command": "aura-mcp", "args": [] }
  }
}

    Claude Desktop: Settings → Developer → Edit Config. On Windows, if AURA doesn’t appear, use "command": "cmd", "args": ["/c", "aura-mcp"].

  4. Step 4 · one time

    Approve on the phone

    Restart your AI app and ask “What’s on my phone screen?” The phone asks “Approve this computer?” Tap Approve once.

This is early and built by one person, so the connection can break sometimes. If it does, open an issue with the run log.

The Barrier Is Down.

What AURA is and what it does, on a real phone.

The things people ask first.

Does AURA watch my screen all the time?+

No. It reads the screen only while doing something you asked for, and stops when the task ends. The numbered screenshot and element list go to the AI model you chose, whether that’s a cloud provider or a model you run yourself. AURA itself has no backend and keeps nothing.

What does it cost?+

The app is free, with no account and no subscription. Bring your own key from any of 13 providers; Groq and Google Gemini have free tiers. You pay your provider directly, if at all.

Why is the download {{ sizeLabel }}?+

The vision models that read your screen ship inside the app instead of on a server. It also carries code for both ARM processor types so one APK works everywhere; per-processor builds are planned.

Why isn’t it on the Play Store?+

It’s coming. For now it ships directly so it can improve quickly. The download steps cover every screen, including the one Android hides.

Can I use it to test my own app?+

Yes. Connect Claude Code, Cursor or any MCP client, install your build on the phone, and describe the flow in plain English. It checks the screen after every step and logs the run on the phone.

Can it log into websites in its browser?+

Yes, when you type the password yourself, and the session stays signed in. Sign in with Google is the exception: Google has blocked its sign-in page inside embedded browsers since 2023, for every app.

Which phones does it work on?+

Android 8.0 or newer on ARM. Xiaomi, OPPO, realme, vivo, OnePlus, Samsung, Huawei, Honor, Pixel and Motorola all work, though some brands add permission switches of their own.

Does it update itself?+

Not automatically; apps installed outside the Play Store can’t. AURA shows a banner when a new version is out. Updates install over the old app and keep your settings, memory and keys.

Can it work without internet?+

Partly. Seeing the screen, the wake word and speaking back work offline. Deciding what to do next needs your AI provider.

Is it stable?+

Honestly, not yet. AURA was built by one person and it’s early, so it can break sometimes: some apps trip it up and a run can stall. You can always stop it, and bug reports with the run log help a lot.

What happens if it does the wrong thing?+

Stop it any time from the floating bubble or the notification. Every step is logged. It is AI and it can be wrong, so anything irreversible deserves your eyes.
